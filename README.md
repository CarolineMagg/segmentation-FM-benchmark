# Benchmark for promptable FMs for segmentation

Code base for prompt extraction from reference masks and inference of 12 foundation model (FM) for segmentation.<br>

## Our study

In our study, we evaluated eleven foundation models that can be prompted with geometric sparse prompts, 
i.e., bounding box and points, on four anatomical regions of muscolosketal (MSK) CT scans.
We compared the FMs' performance with "perfect" prompts (i.e., extracted from the reference labels) to 
define the Pareto-optimal models with the least model parameters. 
These selected models were then analyzed with human-generated bounding boxes and points acquired during an observer study. 
Beyond the analysis of annotation consistency, 
the degree to which input prompt variability influenced the consistency of the resulting segmentations was investigated.

Our main findings:
* The segmentation performance varies a lot between FMs and prompting strategies;
* The segmentation performance drops using human prompts, suggesting that performance reported on perfect prompts extracted from reference labels might overestimate the performance in a human-driven setting;
* All models were sensitive to prompt variations. While two models demonstrated intra-rater robustness, it did not scale to inter-rater settings.

## Overview

### Promptable Foundation models for segmentation 

The following models are included in this repository:

**2D models:**

* SAM
* SAM2 Imagepredictor
* SAM3 Imagepredictor
* Med-SAM
* SAM-Med2D
* ScribblePrompt
* MedicoSAM 2D mode

**3D models:**

* SAM2 Videopredictor
* SAM3 Videopredictor
* Med-SAM2
* SAM-Med3D
* MedicoSAM 3D mode (prompt-propagation)
* SegVol
* VISTA3D
* nnInteractive

All these models:
* are not specific for one dataset or anatomical region, but have been trained on a variety of datasets
* are considered foundation models for segmentation
* have been developed (or used) to test medical image segmentation
* can be prompted with spatial prompts (i.e. bounding box and/or point)

![model overview](/assets/images/models_v4.png)

### Prompting strategies

The supported prompts are static (i.e. non-iterative) and are automatically generated from the reference mask. Alternatively, prompts generated by a human user can be provided in a json-file.

A prompt consists of at least one primitive (i.e., (a) bounding box, (b) center, (c) centroid, (e) positive or (f)
negative random points) and one component selection criteria (i.e., largest or up to 5 components). For 3D prompting, initial slice(s) are provided as $z$-coordinate.

## Installation

### Dependencies

All FMs have different requirements and some of the dependencies are not compatible with each other.
Therefore, we recommend the following three conda environments installations:

1. nnInteractive

````
conda create --name nninteractive python=3.11
conda activate nninteractive
pip install torch==2.6.0 torchvision==0.21.0 torchaudio==2.6.0 --index-url https://download.pytorch.org/whl/cu124
pip install nnunetv2
pip install nibabel natsort tqdm
````

2. MedicoSAM

````
conda create -c conda-forge -n medico_sam micro_sam
conda activate medico_sam
pip install nibabel
````

3. SAM3
Follow these [instructions](https://github.com/facebookresearch/sam3#installation).

3. Other FMs
````
conda create --name sam_family python=3.11
conda activate sam_family
pip install torch==2.5.0 torchvision==0.20.0 torchaudio==2.5.0 --index-url https://download.pytorch.org/whl/cu121
pip install nibabel pandas natsort scikit-image tqdm
pip install notebook matplotlib plotly
pip install albumentations==1.4.24
pip install transformers=4.17
pip install hydra-core==1.3.2 iopath==0.1.10 torchio==0.20.19 edt==3.0.0
pip install monai==1.2.0
````

Do not forget to switch between the environments when you want to run different models or test inference!

Copy your test sample into ``assets/demo/images`` and the corresponding reference mask into ``assets/demo/labels``. <br>
For example, download the publicly available [TotalSegmentator dataset](https://zenodo.org/records/10047292)
and use one of the test samples.

### Prompt extration
Based on the provided reference mask, bounding boxes and points can be extracted by running the 
[2D extraction](https://github.com/CarolineMagg/segmentation-FM-benchmark/blob/main/src/prompt_generator/prompt_generator_2d_for_datasets/extract_2d_prompts.py)
and the 
[3D extraction](https://github.com/CarolineMagg/segmentation-FM-benchmark/blob/main/src/prompt_generator/prompt_generator_3d_for_datasets/extract_3d_prompts.py)
scripts. These scripts can be modified for your own datasets as well.

**2D prompts** are extracted in a slice-by-slice manner and stored as (``2d_prompts``):
* $[x_{min}, y_{min}, x_{max}, y_{max}]$ for bounding boxes
* $[x,y,1]$ for positive points (inside object)
* $[x,y,0]$ for negative points (outside object)

**3D prompts** are stored as:
* $[x_{min}, y_{min}, z_{min}, x_{max}, y_{max}, z_{max}]$ for bounding boxes
* $[x,y,z,1]$ for positive points (inside object).
* 
The prompts are either extracted as 
* **true 3D prompts** (``3d_prompts``), i.e., center, centroid and bounding box defined as 3D objects or
* **3D-pseudo prompts** (``3d_prompts_from_2d``), i.e., 2D prompts are enriched by there z-component (e.g., flat bounding box $[x_{min}, y_{min}, z, x_{max}, y_{max}, z+1]$)<br>
For this extraction, a pandas dataframe with the column information _file_id, slice_id, unique_id_ is required. <br>
Example: patient_01, 20, patient_01_20 - means that for file patient_01, the prompts at the 20th slice should be extracted and the new unique identifier is patient_01_20
